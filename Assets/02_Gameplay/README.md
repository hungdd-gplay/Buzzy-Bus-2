# 02_Gameplay

Core gameplay của từng game (thêm sau, tách khỏi 01_Base).

- `Res/`: tài nguyên (prefab, texture, audio, animation, scene...).
- `Deploy/Model`: dữ liệu (level, cấu hình, ScriptableObject).
- `Deploy/View`: hiển thị (MonoBehaviour gắn object, UI).
- `Deploy/Controller`: logic gameplay (kế thừa GamePlayController, ItemBase, CollectItemBase...).
- `Deploy/Editor`: tool editor riêng của gameplay.
